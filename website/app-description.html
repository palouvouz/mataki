Mataki

Μετατρέπει την οθόνη Waveshare ESP32-S3 Touch 4.3″ σε οθόνη για την IP κάμερα του σπιτιού.

Τι κάνει

Συνδέεται στο Wi-Fi, ανοίγει το MJPEG stream της κάμερας στο τοπικό δίκτυο, το αποκωδικοποιεί πάνω στο ESP32-S3 και το δείχνει σε πλήρη οθόνη 800×480.

  • Ζωντανή εικόνα, με πάντα το πιο πρόσφατο καρέ
  • Άγγιγμα για μπάρα ελέγχου: κατάσταση, fps και κουμπί Reconnect
  • Αυτόματη επανασύνδεση σε Wi-Fi ή stream που χάθηκε
  • Κωδικοί σε ξεχωριστό αρχείο, που δεν ανεβαίνει ποτέ στο GitHub

Τι χρειάζεται

  • Waveshare ESP32-S3-Touch-LCD-4.3
  • IP κάμερα με MJPEG stream και HTTP Basic login
  • Wi-Fi 2.4 GHz
  • Arduino IDE 2 με το πακέτο esp32 3.1.x, βιβλιοθήκες lvgl 8.3.x και JPEGDEC για το build

Εγκατάσταση από release

Κατέβασε το mataki-full.bin από τα Releases και τρέξε:

python -m esptool --chip esp32s3 write_flash 0x0 mataki-full.bin
