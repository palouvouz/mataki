# mataki
Η οθόνη **Waveshare ESP32-S3 Touch LCD 4.3"** (800×480) γίνεται οθόνη για την IP κάμερα του τοπικού δικτύου. Το Mataki (από το «ματάκι») παίρνει το MJPEG stream της κάμερας (`/video/mjpg.cgi`), το αποκωδικοποιεί στο ESP32-S3 και το δείχνει σε πλήρη οθόνη. Με ένα άγγιγμα εμφανίζεται μια μπάρα ελέγχου με τα fps και κουμπί επανασύνδεσης.
