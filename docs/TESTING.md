# Έλεγχοι

## 0. Πριν το firmware: δοκίμασε την κάμερα
Από υπολογιστή στο ίδιο δίκτυο, με VLC: Media, Open Network Stream, `http://192.168.1.47/video/mjpg.cgi` (θα ζητήσει όνομα και κωδικό). Αν δεν παίζει εκεί, δεν θα παίξει ούτε στην οθόνη.

## 1. Compile
- [ ] Το Verify στο Arduino IDE τελειώνει χωρίς errors (έκδοση πακέτου esp32 3.1.x, lvgl 8.3.x).
- [ ] Το `secrets.h` δεν εμφανίζεται στο `git status`.

## 2. Εκκίνηση
- [ ] Στο Serial Monitor εμφανίζεται `[board] touch address: 0x14` (ή `0x5D`).
- [ ] Η οθόνη ανάβει και δείχνει την κάρτα «Starting».
- [ ] Δεν υπάρχουν συνεχείς επανεκκινήσεις (reboot loop).

## 3. Δίκτυο και κάμερα
- [ ] «Joining Wi-Fi», μετά «Connecting to camera», μετά εικόνα.
- [ ] Λάθος κωδικός κάμερας δίνει «Camera rejected the login (401)».
- [ ] Αποσύνδεση κάμερας δίνει κόκκινη κάρτα και μετά αυτόματη επαναφορά.
- [ ] Επανεκκίνηση του router: το Mataki ξαναβρίσκει Wi-Fi και stream μόνο του.

## 4. Εικόνα και αφή
- [ ] Τα χρώματα είναι σωστά (αλλιώς δες `JPEG_BIG_ENDIAN`).
- [ ] Δεν υπάρχουν οριζόντιες σχισμές ή τρεμόπαιγμα.
- [ ] Άγγιγμα ανοίγει/κλείνει τη μπάρα· το Reconnect δουλεύει.
- [ ] Τα fps ανεβαίνουν στο πολύ 15 (ή όσο έχεις ορίσει).

## 5. Αντοχή
- [ ] 1 ώρα συνεχόμενα χωρίς πάγωμα ή επανεκκίνηση.
