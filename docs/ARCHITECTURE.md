# Αρχιτεκτονική

```
Κάμερα --HTTP MJPEG--> [net task, core 0] --> 3 frame buffers (PSRAM)
                              |                      |
                              v                      v
                        βρίσκει FFD8..FFD9     [decode task, core 1]
                                                JPEGDEC -> RGB565
                                                      |
                                                      v
                                   ui_present_frame -> LVGL canvas -> RGB panel
```

| Αρχείο (φάκελος `Mataki`) | Ρόλος |
|---|---|
| `Mataki.ino` | setup(): πλακέτα, UI, Wi-Fi, stream |
| `board.cpp` | I2C (Wire), CH422G (backlight και resets), RGB panel 800×480, αφή GT911 |
| `ui.cpp` | LVGL 8.3: κάρτα κατάστασης, καμβάς βίντεο, μπάρα ελέγχου |
| `wifi_link.cpp` | Σύνδεση Wi-Fi με αυτόματη επανασύνδεση |
| `mjpeg_client.cpp` | TCP/HTTP stream, ανάκτηση καρέ, αποκωδικοποίηση με JPEGDEC |
| `mataki_config.h` | Μη μυστικές ρυθμίσεις |
| `secrets.h` | Μυστικά (δεν ανεβαίνει στο GitHub) |

Τα ονόματα `wifi_link` και `mataki_config` επιλέχθηκαν ώστε να μην μπερδεύονται με τα `WiFi.h` και άλλα αρχεία βιβλιοθηκών σε Windows και macOS (δεν ξεχωρίζουν κεφαλαία/μικρά).

## Βασικές αποφάσεις
- **Μόνο το νεότερο καρέ**: η ουρά ετοίμων καρέ έχει μήκος 1. Αν η αποκωδικοποίηση καθυστερεί, το παλιό καρέ πετιέται, ώστε η εικόνα να μένει ζωντανή.
- **Εύρεση καρέ από τα bytes**: κάθε JPEG ξεχωρίζει από το FFD8 ως το FFD9, χωρίς εξάρτηση από τα boundary headers της κάμερας.
- **Scaling**: αν το καρέ είναι μεγαλύτερο από 800×480, το JPEGDEC το μικραίνει σε 1/2, 1/4 ή 1/8 κατά την αποκωδικοποίηση.
- **Login**: HTTP Basic. Η κεφαλίδα φτιάχνεται στη μνήμη, σβήνεται μετά τη χρήση και δεν τυπώνεται ποτέ.
- **Αφή**: το GT911 διαβάζεται απευθείας με Wire (χωρίς επιπλέον βιβλιοθήκη).
